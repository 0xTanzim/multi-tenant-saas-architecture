# Requirements & Project Overview

This folder contains high-level project requirements and developer orientation materials.

## Files

### 1. CLIENT_REQUIREMENTS.md

**Purpose:** Original functional requirements and system specifications

- User roles and responsibilities (Customer, Owner, Staff, Admin)
- Core business requirements
- Feature specifications
- System constraints and non-functional requirements

**Best for:** Understanding what the system needs to do from a business perspective.

### 2. DEVELOPER_PROJECT_GUIDE.md

**Purpose:** Technical orientation and developer setup

- Architecture high-level overview
- Tech stack and technology choices
- Development setup and environment configuration
- Key directories and module structure
- How to get started as a new developer

**Best for:** New developers getting familiar with the project structure and tech stack.

---

## Reading Order

**For Business Stakeholders:**

1. Start with CLIENT_REQUIREMENTS.md

**For Developers:**

1. Start with DEVELOPER_PROJECT_GUIDE.md
2. Then read CLIENT_REQUIREMENTS.md for context

**For Architects:**

1. Read both files to understand context
2. Then explore `../01-core-concepts/` for deep architecture
